# 양배추 용사단! (MVP)

웹 브라우저에서 4~8명이 함께하는 탑다운 협동 로그라이크. 기획은 [../기획서.md](../기획서.md), 카드는 [../카드목록.md](../카드목록.md).

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 접속 → 방 만들기 → "초대 링크 복사"로 친구에게 공유.
같은 와이파이의 친구는 `http://<내 PC IP>:5173/?room=코드` 로 접속.

배포용:

```bash
npm run build
npm start
```

(서버 하나가 빌드된 화면과 WebSocket을 함께 서빙, 기본 포트 2567 또는 `PORT`)

## 조작
WASD 이동 · 마우스 조준 / 좌클릭 공격 · Space 대시 · **1~4 누른 채 좌클릭 = 그 위치에 스킬** (키를 떼면 취소) · E 암시장 · Enter 휴게소 준비 완료 · 카드/투표는 클릭 또는 숫자키

## 들어간 것 (v0.2)
- 방 코드로 입장, 로비(직업 선택·준비·방장 시작), 최대 8명
- 직업 4종 × 스킬 4개 (Lv 1 / 3 / 6 / 10 해금), 롤 방식 범위 표시 조준
- 월드 1: 6라운드 + 보스 「왕 슬라임」 (랜덤 맵), 라운드마다 몬스터 증가
- 개인 레벨·경험치 (넣은 피해 비율만큼), 돈은 기여도 1위가 전부 (보스는 생존자 균등)
- 카드 61장: 매 라운드 개인 카드, 3라운드마다 50% 팀카드 투표 / 50% 암시장
- 휴게소: 암시장(일반 30 / 희귀 80 / 전설 200원 상자), DPS 허수아비, 스킬 쿨타임 없음, 전원 준비 시 진행 (최대 120초)
- 유령 상태 + 동료 근처 3초 부활, 전멸 시 패배, 결과 화면 + 칭호

## 모드 / 저장 / 순위
- **일반**: 월드를 깰 때마다 서버에 자동 저장. 방장 이름으로 된 저장을 로비에서 골라 이어하기 (같은 닉네임은 캐릭터 복구)
- **스피드런**: 로비에서 바로 선택. **각자 자기 맵에서 솔로로 동시에 경주** (오른쪽에 모두의 진행 현황). 카드·투표·휴게소 시간 제외 타이머, 월드별 구간·완주 개인 순위 (서버 공용)
- **보석 쟁탈전** (서브 모드): 레벨 10 + 카드 드래프트 5장 → 아레나. 보석 든 사람만 공격하고 공격받음. 보석 점수(초당 1점) 100점 먼저 모으면 우승
- **하드코어**: 8월드를 깬 닉네임이 방장이면 선택 가능 (난이도 ×4)
- 저장·순위 파일: `data/store.json` (환경변수 `STORE_FILE`로 바꿀 수 있음)

## v0.4 편의 기능 · 난이도 · 이벤트
- **Tab 메뉴** (로비·게임 어디서나, 게임은 계속 진행): 도감(카드·몬스터·직업) / 설정 / 커맨드
- **설정** (브라우저에 저장): 평타 막대·스킬 범위·돌진 예고선 켜고 끄기, 키 바꾸기, 스킬 조준 방식(누른 채 클릭 / 누르면 바로 시전), 명령어 입력
- **커맨드 패널**: 닉네임이 GRD인 사람이 설정의 명령어 칸에 비밀번호를 입력하면 열림 (서버가 확인, 접속할 때마다). 쓴 판은 순위·저장·해금·도감 기록 안 남음
- **난이도**: 쉬움 ×1 / 보통 ×2 (기본) / 어려움 ×3 / 하드코어 ×4 — 적 체력 ×배율, 피해 ×(1+배율)/2. 순위는 난이도별
- 공통 조정: 라운드 사이 회복 15%, 부활 5초·체력 30%, **엘리트 몬스터**(분노·분열·보호막·흡혈·순간이동)
- 3라운드 이벤트: 팀카드 50% / 암시장 35% / **도박꾼** 15% (홀짝·룰렛·카드 도박). 라운드 클리어 시 20% **시련의 방** 투표

## v0.6 PANIC · 카드 그림 · 모드 선택
- **PANIC** (로비 모드): 16구역 × 1분 30초 협동 타임어택. 임무(몬스터 전멸 / 탈출구 도달 / 열쇠 수집 중 무작위) + 몬스터 전멸을 둘 다 해야 돌파, 16구역은 최종 보스. 0초면 TIME OVER, 돌파하면 COMPLETE! → 카드 1장 → 다음 구역. 난이도별 클리어 시간 순위, 업적 3개. 테스트용 `START_ZONE=15`
- 효과음(Web Audio로 직접 만든 소리): 설정에서 끄기·음량·PANIC 붉은 경고 끄기
- **카드 그림**: 67장 모두 효과를 알아볼 수 있는 도트 그림 + 작은 표시(↑ ↓ + 동전) — `client/cardArt.ts`
- **모드 선택**: 로비의 「모드 선택」 → 큰 배너를 좌우로 넘겨 고르고 그 아래에서 난이도 선택
- 결과 화면 **재도전** 버튼 (방장은 같은 모드로 바로 다시 시작)

## v0.8 보물방 · 소리 · 재접속
- **보물방** (랜덤방, 일반 라운드 클리어 시 15% · 시련의 방 15%): 작은 방에 상자 4개 — 20 / 50 / 60원 + 미믹 1개, 사람마다 배치가 따로 무작위. 미믹을 열면 가진 돈을 전부 잃고 더는 못 엶. 결과는 나에게만 보임. 출구에 모두 모이거나 40초가 지나면 카드 선택. 커맨드 `이동 → 보물방으로`
- **배경음악** (기본 꺼짐, 설정 → 배경음악 켜기): 코드로 만든 8비트 곡 — 월드 8곡 · 보스 · 로비 · 휴게소 · 보물방 · PANIC(남은 시간이 줄수록 빨라짐)
- **효과음**: 평타·타격·처치·피격·대시, 스킬별 소리, 버튼·포탈·부활·보스 등장·패배. 설정에서 전체 / 효과음 / 배경음악 음량 따로
- **게임 중 재접속**: 끊기면 60초 동안 캐릭터가 무적으로 남고 머리 위에 "연결끊김!". 자동으로 다시 연결되고, 새로고침해도 같은 닉네임으로 이어서 플레이
- PANIC 타이머: 45초부터 노랑, 20초부터 빨간 점멸 + 붉은 테두리 + 사이렌, 10초부터 더 빠르게
- 저주 교체 (멀티에서 어그로 문제): 반짝반짝 → **유리 심장**(피해 +25%, 받는 피해 +25%), 시끄러운 갑옷 → **기분파**(공속 +35%, 10초마다 3초간 공격력 절반)
- 로비 준비·시작 버튼을 순위 칸 너비로

## 테스트
```bash
npm test
```
서버 게임 로직 점검 164개 (암시장·투표·카드 특수효과·레벨·기여도·월드 진행·저장/이어하기·지형·난이도·스피드런·순위·보석 쟁탈전·엘리트·도박꾼·시련의 방·커맨드·도감·새 직업·업적·코스튬·무한 하강).

`npm run sim` 옵션: `SIM_NEW=1` 새 직업 3종으로, `SIM_DESCENT=40` 무한 하강 40층까지, `SIM_PANIC=1` PANIC 16구역.

친구 서버(2567)를 켜 둔 채 개발 화면을 보려면 `npm run dev:test` (게임 서버 2577 + 화면 http://localhost:5174, 기록은 `data/store-test.json`).

```bash
npm run sim
```
아주 강한 테스트 용사 3명으로 8월드 전체를 자동 진행 (모든 몬스터·보스 패턴이 멈추지 않는지 점검).

개발 중 원하는 지점을 빨리 보고 싶으면 환경변수로 지정할 수 있어요 (PowerShell):
```bash
$env:START_WORLD='5'; $env:START_ROUND='7'; npm run dev
```
`START_WORLD=1~8` 시작 월드, `START_ROUND=7` 이면 바로 보스, `FORCE_EVENT=rest|vote|gambler` 매 라운드 그 이벤트, `FORCE_TRIAL=1` 매 라운드 시련의 방 투표.

친구들과 노는 서버를 켜 둔 채로 테스트하려면 포트·빌드 폴더를 따로 쓰세요: 서버는 `PORT`·`DIST_DIR`·`STORE_FILE`, 개발 화면(vite)은 `GAME_PORT`로 붙일 게임 서버 포트를 지정할 수 있어요.

## 구조
- `shared/` 직업·카드·프로토콜·충돌 (서버/클라이언트 공용)
